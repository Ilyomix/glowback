Umgebungslicht für die RGB-LEDs auf der Rückseite deines Monitors.

Glowback erfasst deinen Bildschirm und gibt jeder LED dahinter live die Farbe des Bildes direkt vor ihr. Deine Wand wird Teil des Bildes.

So funktioniert's

Drei Schritte, dreißigmal pro Sekunde, in etwa einer halben Millisekunde CPU-Zeit.

01

Erfassen

Die GPU liefert jedes neue Bild (DXGI, HDR inklusive) und verkleinert es auf ein winziges Farbraster. Schwarze Balken von Filmen werden ignoriert.

02

Zuordnen

Jede LED meldet ihre physische Position. Glowback projiziert sie auf den nächstgelegenen Bildschirmrand, wie bei einem Ambilight-Fernseher.

03

Leuchten

Die Farben werden geglättet, in dunklen Szenen aufgehellt und per USB an die LEDs gesendet. Nichts verlässt deinen PC.

Eine Zone pro LED

Jede LED folgt ihrem eigenen Bildausschnitt, oder du wechselst zu einer einzigen Durchschnittsfarbe.

Filme, Spiele, HDR

Videos und Spiele im Vollbild, HDR-Desktop, Erkennung schwarzer Balken.

Native Windows-App

Installer, Startmenü, Start mit Windows, saubere Deinstallation über die Einstellungen.

Updates mit einem Klick

Glowback prüft täglich GitHub, verifiziert den Download und aktualisiert sich selbst.

Teil deines Smart Homes

Glowback erscheint in Home Assistant als Licht: Dashboards, Automationen und dein Sprachassistent können es ein- und ausschalten oder dimmen. Das Glowback-Panel und Home Assistant bleiben dabei synchron.

Home Assistant

light.glowback

An/Aus, Helligkeit und der Modus als Effekt (Zones oder Average). Dazu eine Update-Entität, mit der du neue Versionen siehst und installierst, und ein Sensor für die Anzahl der LEDs.

Google Assistant

„Hey Google, stell Glowback auf 50 %“

Über Home Assistant Cloud oder die manuelle Einrichtung von Home Assistant.

Alexa

„Alexa, schalte Glowback aus“

Ebenfalls über Home Assistant: Home Assistant Cloud oder die manuelle Einrichtung.

Siri und Apple Home

„Hey Siri, schalte Glowback ein“

Über die Integration HomeKit Bridge von Home Assistant, mit An/Aus und Helligkeit. Apple Home kennt keine Lichteffekte, daher gibt es dort keinen Modus.

Einrichtung im Panel

Installiere in Home Assistant die App Mosquitto broker. Klicke dann im Glowback-Panel auf Home Assistant und gib Adresse, Port, Benutzer und Passwort ein.

Der MQTT-Client ist eingebaut, und das Passwort wird für dein Windows-Konto verschlüsselt (DPAPI).

Oder per Kommandozeileglowback --home-assistant mqtt://BENUTZER:PASSWORT@HOSTSchritt-für-Schritt-Anleitung (Englisch) →

Alles direkt neben der Uhr

Ein Klick auf das Symbol im Infobereich öffnet ein Panel. Einstellungen wirken sofort, und das Panel bleibt offen, während du sie anpasst.

  • Live-Status: aktiv, pausiert, Anzahl der LEDs
  • Schalter für Umgebungslicht und Start mit Windows
  • Home Assistant: in einem kleinen Fenster eingerichtet, Status auf einen Blick
  • Jede LED folgt ihrer Zone, oder eine Durchschnittsfarbe
  • Helligkeit mit einem Tipp: 25, 50, 75 oder 100 %
  • Updates mit einem Klick suchen oder täglich automatisch

Funktioniert mein Monitor?

Glowback ist an keine Marke gebunden. Trifft einer dieser Fälle zu, funktioniert es.

Dynamische Beleuchtung von Windows

Dein Monitor erscheint unter Einstellungen → Personalisierung → Dynamische Beleuchtung. Glowback steuert ihn direkt.

OpenRGB

Deine LEDs werden von OpenRGB unterstützt. Starte dessen SDK-Server, und Glowback findet sie automatisch.

Weder noch?

Fragen

Welche Monitore werden unterstützt?

Jeder Monitor, dessen RGB-Beleuchtung auf der Rückseite über die dynamische Beleuchtung von Windows oder über OpenRGB steuerbar ist. Führe glowback --list aus oder suche deinen Monitor unter Einstellungen → Personalisierung → Dynamische Beleuchtung.

Muss ich etwas ausschalten?

Ja: Schalte die dynamische Beleuchtung von Windows für deinen Monitor aus (Einstellungen → Personalisierung → Dynamische Beleuchtung), sonst streiten sich Windows und Glowback um die LEDs.

Windows sagt, es habe meinen PC geschützt. Ist das sicher?

Der Installer ist noch nicht codesigniert, daher kennt SmartScreen ihn nicht. Klicke auf Weitere Informationen → Trotzdem ausführen. Der Quellcode und jeder Build sind öffentlich auf GitHub, und Updates in der App werden anhand der veröffentlichten SHA-256-Prüfsummen verifiziert.

Funktioniert es mit HDR, Spielen und Filmen im Vollbild?

Ja. Die GPU-Erfassung kommt mit Vollbild-Spielen, Videoplayern und HDR-Desktops zurecht, und schwarze Balken bei Filmen werden ignoriert. DRM-geschützte Streams zeigt Windows meist jedem Aufnahme-Tool nur schwarz.

Funktioniert es mit Siri, Google Assistant oder Alexa?

Ja, über Home Assistant. Glowback erscheint dort per MQTT als Licht, über die App Mosquitto broker von Home Assistant. Google Assistant und Alexa funktionieren dann über Home Assistant Cloud oder die manuelle Einrichtung von Home Assistant. Siri und Apple Home funktionieren über die Integration HomeKit Bridge, mit An/Aus und Helligkeit: Apple Home kennt keine Lichteffekte, daher fehlt dort der Modus.

Wie deinstalliere ich es?

Einstellungen → Apps → Installierte Apps → Glowback → Deinstallieren. Die LEDs kehren zum eigenen Effekt des Geräts zurück.
